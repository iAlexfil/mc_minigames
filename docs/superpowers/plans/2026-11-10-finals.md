# The Finals Implementation Plan

> **For agentic workers:** Use executing-plans for the session and independent agents for the state model, arena and integration.

**Goal:** Play a complete simplified Cashout match in Minecraft.
**Architecture:** Pure deadline/state model, disposable generated arena, Paper event adapter; existing queue/menu/player lifecycle services.
**Tech Stack:** Java 25, Paper 26.3 (26.2 compatible), Gradle, paired YAML catalogs.
**Spec:** `docs/superpowers/specs/2026-11-10-finals-design.md`

## Global constraints
- Preserve other games, use session-scoped worlds/HUD/messages, and restore players through core cleanup.
- Fixed red/blue teams; 2–12 players with solo practice; all new text in English and Russian.
- No new runtime dependencies and no server deployment in this task.

## Review focus
- Cashbox death/disconnect/drop and stale entities never duplicate money.
- Cashout deadline beats a simultaneous steal; no duplicate payout or point award.
- Respawn invulnerability cannot protect an attacker or objective interaction.
- Leaving/ending blocks further events; delayed tasks and explosives cannot leak into another game.
- Geometry preserves safe spawns, routes, floor and objectives after destruction.

## Tasks
- [x] State: write deadline/ownership/withdrawal checks, observe red, implement `FinalsState` and run checks.
- [x] Arena: generate symmetric arena with explicit cover permissions; verify geometry and protected surfaces.
- [x] Session: implement countdown, objectives, combat, respawn, HUD, results, reconnect and cancellation using the state/arena APIs.
- [x] Integration: register FinalsGame, add clamped config and bilingual catalogs, Gradle checks and README commands.
- [x] Verification: run full build/i18n plus available local server smoke; independent review and repair material findings.

State interface is recorded in `FinalsState`; the session uses integer teams 0/1. Arena interface: `build`, `center`, `spawn(team,index)`, `vault`, `station(index)`, `contains`, `isCover`, `stationAt`, `isVault`. The mode integrates through `FinalsSession(SessionServices, FinalsConfig)`.
