The bundled block palette/coordinates are converted directly from the Java world;
no arena architecture is generated by this plugin. The architectural bounds are
X -25..130, Z -34..119; source Y 9..45 is translated upward by 64 blocks. Buried
and distant generated terrain is omitted. Original Java 1.16 block identifiers
are updated where renamed by Minecraft. Entities, player data, inventories,
commands and scripts are not loaded. Gameplay spawns and bomb/buy zones are
metadata placed on existing surfaces. Invisible outer clipping contains play.

Reproduce with Python 3, using only the standard library:

    python3 tools/import_cs_dust2.py assets/maps/lesraisins-dust2/source-dust2.zip src/main/resources/maps/cs/dust2.bin.gz
